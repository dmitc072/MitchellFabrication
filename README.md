# Mitchell Creative & Fabrication

A business website built with **Blazor (.NET 8)** for a veteran-owned fabrication and print company based in Conyers, GA.

## Features
- Service showcase with interactive selection
- Pricing table
- Quote request form
- Responsive layout with mobile carousel
- SDVOSB / veteran-owned business info

## Tech Stack
- Blazor Web App (.NET 8)
- C#
- CSS (component-scoped + global)
- Bootstrap (CSS only)

## Running Locally
```bash
dotnet run
```
